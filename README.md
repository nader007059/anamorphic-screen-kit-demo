# Anamorphic Screen Kit — Demo

Free demo of **Anamorphic Screen Kit**, a Blender add-on to create anamorphic 3D content for LED screens.

You describe the real screen (its size in metres, its LED pitch and where the audience stands). The add-on builds the camera rig and a virtual room behind the screen, then renders a pixel-accurate canvas for the LED wall.

## Download

Get `anamorphic_screen_kit_demo-1.0.0.zip` from the [latest release](https://github.com/nader007059/anamorphic-screen-kit-demo/releases/latest).

## Install

1. Blender 5.0 or newer.
2. `Edit > Preferences > Get Extensions`, open the drop-down menu at the top right and choose `Install from Disk...`.
3. Pick the zip file. Do not unzip it.
4. In the 3D viewport press `N` and open the **Anamorphic** tab.

## What the demo does

- Flat LED screens, from real dimensions and LED pitch
- Guided setup: screen, audience position, virtual room, output, check
- Safe zone, view from the audience, preview on the wall
- One lighting preset (Daylight)
- LED canvas rendered as a still image, with a DEMO watermark

## Full version

The full version adds corner, rounded-corner and curved screens, custom mesh screens, all lighting presets, animation rendering and canvases without watermark.

Do not enable the demo and the full version at the same time: disable one before enabling the other.
